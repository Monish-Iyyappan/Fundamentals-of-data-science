# Fundamentals of Data Science (FDS)

## 📚 About This Repository

This repository contains my **Fundamentals of Data Science (FDS)** practical programs and important theoretical concepts learned during the course.

The practical work focuses on understanding how Python and its libraries are used for **data analysis, visualization, preprocessing, statistics, and machine learning**.

Along with practical implementation, I have also studied the basic theoretical concepts required to understand how these techniques work.

---

## 🎯 Objectives

The main objectives of this course are:

- Understand the fundamentals of Data Science.
- Learn Python libraries used in Data Science.
- Perform data collection and exploration.
- Analyze and visualize datasets.
- Understand data preprocessing techniques.
- Handle missing and inappropriate data.
- Detect outliers.
- Perform feature scaling.
- Understand statistical concepts and hypothesis testing.
- Understand Exploratory Data Analysis (EDA).
- Implement basic Machine Learning algorithms.
- Understand supervised and unsupervised learning.
